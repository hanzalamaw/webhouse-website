# WebHouse Inc. Website

A modern, professional website for WebHouse Inc. - a strategic digital execution partner for forward-thinking enterprises.

## 🚀 Features

- **Modern Design**: Clean, professional UI with dark mode support
- **Responsive**: Fully responsive design that works on all devices
- **Performance**: Optimized for fast loading and smooth animations
- **Accessibility**: Built with accessibility best practices
- **SEO Optimized**: Proper meta tags and semantic HTML

## 📁 Project Structure

```
webhouseinc_website/
├── index.html              # Main HTML file
├── coming-soon.html        # Coming soon page
├── about.html              # About page
├── services.html           # Services page
├── case-studies.html       # Case studies page
├── how-we-work.html        # Methodology page
├── css/
│   └── styles.css          # Custom styles
├── js/
│   ├── main.js             # Main JavaScript functionality
│   └── tailwind-config.js  # Tailwind CSS configuration
├── assets/
│   └── images/
│       └── logo.png        # Company logo
├── netlify.toml            # Netlify deployment configuration
├── .gitignore              # Git ignore file
└── README.md               # This file
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **Tailwind CSS**: Utility-first CSS framework (via CDN)
- **JavaScript**: Vanilla JS for interactivity
- **Material Symbols**: Icon library

## 📝 Setup Instructions

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build process required - works directly in the browser

## 🚀 Deployment

### Netlify Deployment

This site is ready to deploy to Netlify:

**Quick Deploy Options:**
1. **Drag & Drop**: Go to [app.netlify.com](https://app.netlify.com) and drag your project folder
2. **Git Integration**: Connect your GitHub/GitLab repo to Netlify
3. **CLI**: Use `netlify deploy` after installing Netlify CLI

See `NETLIFY_DEPLOYMENT.md` for detailed deployment instructions.

**Note:** The `coming-soon.html` page is included and can be accessed at `/coming-soon.html` or configured as a maintenance page.

## 🎨 Customization

### Colors
Edit the Tailwind configuration in `js/tailwind-config.js` to customize the color scheme.

### Content
Edit `index.html` to update content, sections, and structure.

### Styles
Custom styles can be added to `css/styles.css`.
